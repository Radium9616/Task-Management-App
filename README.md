Task Management App.
A Python-based productivity application that helps you stay on top of your work by tracking tasks, sorting them by difficulty and scoring your daily performance based on completion. Open main.py and run it.
Features

Add and manage tasks with difficulty levels
Sort tasks by difficulty to prioritise your workload
Score tracking system that rewards task completion
Daily performance evaluation based on unfinished tasks at end of day

Getting Started
Prerequisites: Python 3.x installed on your machine
